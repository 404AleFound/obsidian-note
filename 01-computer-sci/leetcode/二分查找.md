# 题目

给定一个 `n` 个元素有序的（升序）整型数组 `nums` 和一个目标值 `target`  ，写一个函数搜索 `nums` 中的 `target`，如果 `target` 存在返回下标，否则返回 `-1`。

你必须编写一个具有 `O(log n)` 时间复杂度的算法。

  
**示例 1:**

**输入:**  `nums = [-1,0,3,5,9,12], target = 9`
**输出:** `4`
**解释:** `9 出现在 nums 中并且下标为 4`

# 题解

定义区间 `[left, right]`，该区间为闭区间，意思是 `target` 有可能在边界上取到，因此对应的：
- `nums[mid] < target` 和 `nums[mid] > target`，这边不能写小于等于或者大于等于，因为要把 `target` 排除在区间之外。
- `left = mid + 1` 和 `right = mid - 1`，因为这样才能让区间包含 `target`。

```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
	    int size = nums.size();
	    int left = 0;
	    int right = nums.size() - 1;
	    int mid;
	    while (left <= right) {
		    mid = left + (right - left) / 2;
			if (nums[mid] < target) {
				left = mid + 1;
			} else if (nums[mid] > target) {
				right = mid - 1;
			} else {
				return mid;
			}
	    }
	    return -1;
    }
};
```

改一下写法，这样写更好点，可以少写一个分支判断：

```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
		int left = 0;
		int right = nums.size() - 1;
		int mid = 0;
		int ans = nums.size();
		while (left <= right) {
			mid = left + (right - left) / 2;
			if (target <= nums[mid]) {
				ans = mid;
				right = mid - 1;
			} else {
				left = mid + 1;
			}
		}
        if (ans < nums.size() && nums[ans] == target) // 需要做一次检查
		    return ans;
        return -1;
    }
};
```
# 分析
## 空间复杂度
空间复杂度为 `O(1)` ，算法只使用了若干个固定大小的临时变量，没有借助额外的数组或递归调用栈，空间开销为常数。
## 时间复杂度
时间复杂度为 `O(log n)` ，每次循环将搜索范围缩小一半，最多执行 `⌊log₂(n)⌋ + 1` 次比较，因此时间复杂度为对数级别。
