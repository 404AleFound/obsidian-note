# 题目

给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

**示例 1：**

![](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2018/10/22/rainwatertrap.png)

**输入：** `height = [0,1,0,2,1,0,1,3,2,1,2,1]`
**输出：** `6`

# 题解

```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        stack<int> stk;
        int res = 0;
        stk.push(0);
        for (int i = 1; i < height.size(); i++) {
            if (height[i] < height[stk.top()]) {
                stk.push(i);
            } else if (height[i] == height[stk.top()]) {
                stk.pop();
                stk.push(i);
            } else if (height[i] > height[stk.top()]) {
                while (!stk.empty() && height[stk.top()] < height[i]) {
                    int mid = stk.top();
                    stk.pop();
                    if (!stk.empty()) {
                        int left = stk.top();
                        int right = i;
                        int w = right - left - 1;
                        int h = min(height[left], height[right]) - height[mid];
                        res = res + w * h;
                    }
                }    
                stk.push(i);
            }
        }
        return res;
    }
};
```
