# 课题名称

**基于计算机视觉的管道淤泥识别算法研究**

# 研究内容

## 研究内容 1：管道淤泥的图像数据集构建

1. 基于开源数据和实采数据的管道淤泥标准数据集构建（各种成像环境）（标签：有无流 + 淤泥类型  + 淤积程度）
2. 图像数据集增广算法研究（基于深度学习的）

## 研究内容 2：基于视觉的管道淤泥识别算法研究

拟输出的三元信息（有无流 + 淤泥类型 + 淤积程度），拟采用语义分割相关算法进行淤泥识别，理由如下：

由于需要对淤积程度进行辨别，而图像分类和目标检测任务均无法对淤积程度进行度量，但是分割

1. 参考现有的语义分割算法，设计语义分割算法框架（特征提取 + 上采样 + 特征融合等）
2. 基于有/无流数据集，对算法中的各个模块对应的范式进行对比实验，
3. 基于对比结果进行算法优化（尝试相关模块和架构，例如注意力机制、残差等等），并辅以实验验证

## 研究内容 3：管道淤泥视觉识别方案的集成与部署

1. 淤泥识别视觉方案集成与设计
2. 视觉方案的嵌入式部署与实验验证

# 创新点

创新点1：提出一种基于深度学习的图像数据增广算法

创新点2：提出一种适合管道环境的淤泥识别视觉算法
