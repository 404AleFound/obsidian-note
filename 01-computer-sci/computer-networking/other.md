# 节点时延

节点处理时延包括：处理时延（processing delay）、排队时延（queuing delay）、传输时延（transmission delay）、传播时延（propagation delay）：
- 处理时延：检查报文首部和决定将该分组导向何处所需要的时间。
- 排队时延：该分组再节点上等待被传输所需的时间。
- 传输时延：将分组的所有比特推向链路所需要的时间。
- 传播时延：从该链路起点到目标路由器传播所需要的时间。

>[!note]
>关于传输时延的补充：
>用 L 表示该分组的长度，用 R 表示从路由器 A 到路由器 B 的链路传播速率，传输时延就是 L/R。

有：
$$
d_{nodal} = d_{proc} + d_{queue} + d_{trans} + d_{prop}
$$
节点时延最为复杂和有趣的就是排队时延。排队时延很大程度取决于流量到达该队列的速率、链路的传输速率和到达流量的性质，即流量是周期性到达的还是以突发形式到达的。

假如用 a 表示分组到达队列的平均速率，同时假定所有分组都是由 L bit组成的，那么比特到达队列的速率就是 aL bps。比率 La/R 被称为流量强度，其在估计排队时延的范围方面经常起到重要的作用：
- 如果 La/R > 1，则代表比特到达队列的平均速率超过从该队列传输出去的速率
- 如果 La/R < 1，则代表每分组到达时都是一个空队列。但是，如果分组以突发形式到达，而不是周期性到达

# 端到端时延

端到端时延是由无数个节点时延组合而来的。假定在源主机和目标主机之间有 N - 1 台路由器，同时还应该假设此时网络是无拥堵的，因此排队时延是可以忽略不记的。

# 计算机网络的吞吐量

除了时延和丢包之外，计算机网络中另一个至关重要的性能指标就是端到端的吞吐量
