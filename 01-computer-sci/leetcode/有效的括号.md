# 题目

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

**示例 1：**

**输入：** `s = "()"`

**输出：** `true`

# 题解

```cpp
class Solution {
private:
    unordered_map<char, char> dict {
        {')', '('},
        {'}', '{'},
        {']', '['}
    };
public:
    bool isValid(string s) {
        stack<char> stk;
        
        for (int i = 0; i < s.size(); i++) {
            if (dict.find(s[i]) == dict.end()) {
                stk.push(s[i]);
            } else {
                if (!stk.empty() && dict[s[i]] == stk.top()) {
                    stk.pop();
                } else {
                    return false;
                }
            }
        }
        return stk.empty();
    }
};
```
