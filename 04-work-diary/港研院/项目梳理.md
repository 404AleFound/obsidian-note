# 课题名称

**基于计算机视觉的管道淤泥识别算法研究**

# 研究内容

## 研究内容 1：管道淤泥的图像数据集构建

1. 基于开源数据和实采数据的管道淤泥标准数据集构建（各种成像环境）（标签：有无流 + 淤泥类型  + 淤积程度）
2. 图像数据集增广算法研究（基于深度学习的）

## 研究内容 2：基于视觉的管道淤泥识别算法研究

最终拟输出的信息为淤泥类型与淤积程度，目前打算作为语义分割任务完成。

由于需要对淤积程度进行输出，而图像分类和目标检测任务均无法对淤积程度进行度量，但对于分割算法来说，其可以以像素级别的粒度对淤积区域进行划分，一定程度上代表了淤积程度的多少（少淤积，像素区域小；多淤积，像素区域大）

1. 结合语义分割re
2. 参考现有的语义分割算法，设计语义分割算法框架（特征提取 + 上采样 + 特征融合等）
3. 基于所构建的数据集，将框架中的各个模块（特征提取模块、上采样模块、特征融合方式等）替换为各种范式，并开展对比实验，以分析不同配置对算法性能的影响。
4. 基于对比实验结果，框定最终的算法方案。

## 研究内容 3：管道淤泥视觉识别方案的集成与部署

1. 淤泥识别视觉方案集成与设计
2. 视觉方案的嵌入式部署与实验验证

# 创新点

创新点1：提出一种基于深度学习的图像数据增广算法

创新点2：提出一种适合管道环境的淤泥识别视觉算法
