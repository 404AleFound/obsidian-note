# 题目

给你一个字符串 `s`，找到 `s` 中最长的 回文 子串。

**示例 1：**

**输入：** `s = "babad"`
**输出：**`"bab"`

# 题解

```cpp
class Solution {
public:
    string longestPalindrome(string s) {
        vector<vector<bool>> dp(s.size(), vector<bool>(s.size(), false));
        int len = 0;
        int index = 0;
        for (int i = s.size() - 1; i >= 0; i--) {
            for (int j = i; j < s.size(); j++) {
                if (s[i] == s[j]) {
                    if (j - i <= 1) {
                        dp[i][j] = true;
                    } else {
                        dp[i][j] = dp[i + 1][j - 1];
                    }
                }

                if (dp[i][j]) {
                    if (j - i + 1 > len) {
                        len = j - i + 1;
                        index = i;
                    }
                }
            }
        }
        return s.substr(index, len);
    }
};
```
