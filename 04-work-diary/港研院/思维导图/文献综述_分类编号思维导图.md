# 管道淤积视觉分类文献综述

> 共83篇，沿用原思维导图的分层条目格式，连续编号；以管底沉积物为应用对象，基础方法和综述背景在独立子节点中标明。
> 日期优先采用正式卷期或论文集发表年月，会议仅有召开日期时采用会议月；网络首发、学位论文及预印本另行标明，详细日期和原文图表依据见随附核验说明；数据均保留原文指标、数据集或实验条件。
> “仅识别”指尚未完成淤泥严重度评价，可包括分类、定位与分割；多缺陷论文仅提取沉积物相关内容，整体指标均注明范围；第二类区分识别后分级、直接等级分类和几何量化，第三类区分管道场景实验与通用方法借鉴。

## 一、仅进行淤泥识别

- 淤泥存在性分类、数据与标签
	- [001]【2019-05】Li等
		- 论文：[Sewer damage detection from imbalanced CCTV inspection data using deep convolutional neural networks with hierarchical classification](<https://doi.org/10.1016/j.autcon.2019.01.017>)
		- 针对正常图像占比过高造成管道缺陷识别偏向多数类的问题，基于修改后的ResNet-18构建先区分正常与异常、再判别具体缺陷的分层分类方法，在来自24.7公里管道巡检的数据上将上层正常／异常分类准确率由78.4%提高至83.2%，并在下层保留独立的沉积淤塞DS类别以支持后续识别。
	- [002]【2019-08】Meijer等
		- 论文：[A defect classification methodology for sewer image sets with convolutional neural networks](<https://doi.org/10.1016/j.autcon.2019.04.013>)
		- 针对人工检查管道图像耗时以及随机划分数据易高估识别能力的问题，采用包含管底沉积物标签的多标签卷积神经网络，并按整次巡检实施交叉验证以接近实际应用条件，在逾200万张、12类缺陷图像的研究中估算可减少最多60.5%的人工复核工作量，但尚不能完全替代人工判读。
	- [003]【2021-06】Haurum和Moeslund
		- 论文：[Sewer-ML: A Multi-Label Sewer Defect Classification Dataset and Benchmark](<https://openaccess.thecvf.com/content/CVPR2021/html/Haurum_Sewer-ML_A_Multi-Label_Sewer_Defect_Classification_Dataset_and_Benchmark_CVPR_2021_paper.html>)
		- 针对管道缺陷数据规模有限且缺少统一评价基准的问题，汇集3家企业9年间75,618段巡检视频的约130万张图像并建立包含管底沉积物AF标签的多标签数据集，通过按视频划分数据和引入类别重要性加权指标比较12种算法，最优基准的测试集总体F2CIW为55.11%、正常类F1为90.94%，为沉积物存在识别提供了数据与评价依据。
	- [004]【2021-11】Dang等
		- 论文：[Deep learning-based sewer defect classification for highly imbalanced dataset](<https://doi.org/10.1016/j.cie.2021.107630>)
		- 针对管道图像分类及类别不平衡问题，调优VGG-19提取与分类缺陷特征，并进一步结合梯度提升和代价敏感学习研究不平衡分类，在每类700张的八类测试集中将含粉砂沉积的debris silty类别正确识别684张，原文报告该类正确率为97.7%，表明深度特征能够用于沉积物类别判别。
	- [005]【2022-01】Haurum等
		- 论文：[Multi-Task Classification of Sewer Pipe Defects and Properties Using a Cross-Task Graph Neural Network Decoder](<https://openaccess.thecvf.com/content/WACV2022/html/Haurum_Multi-Task_Classification_of_Sewer_Pipe_Defects_and_Properties_Using_a_WACV_2022_paper.html>)
		- 针对管道缺陷与水位、材质和形状等任务之间的信息难以共享的问题，提出跨任务图神经网络解码器CT-GNN联合学习这些属性，在ResNet-50配置和Sewer-ML测试条件下，CT-GAT的总体缺陷F2CIW由普通多任务模型的58.29%提高至60.57%，为沉积物分类引入场景属性提供了可借鉴的方法。
	- [006]【2022-03（学位论文）】张力
		- 论文：[基于机器视觉的城市排水管道内部缺陷检测方法研究](<https://doi.org/10.27461/d.cnki.gzjdx.2022.001786>)
		- 针对管道图像质量不足、类别分布不均以及困难样本影响分类的问题，张力结合图像去噪与增强、上下文编码器数据扩增和 LFM-PDARTS 网络搜索及样本加权，在包含管底沉积类别的真实管道图像实验中获得总体准确率 95.90%、F1 值 91.59%，提高了多类管道缺陷识别能力。
	- [007]【2022-12】Haurum等
		- 论文：[Multi-scale hybrid vision transformer and Sinkhorn tokenizer for sewer defect classification](<https://doi.org/10.1016/j.autcon.2022.104614>)

	- [008]【2025-01】Zuo等

		- 针对多标签管道图像中缺陷区域不突出、类别关系未得到充分利用的问题，结合掩膜注意力特征增强、标签相关性学习及类别加权，在包含管底沉积物AF标签的完整Sewer-ML数据集上取得验证集总体F2CIW 73.15%、测试集71.98%，提高了多类别共现条件下的识别表现。
	- [009]【2026-02】Yildizli等
		- 论文：[Self-supervised learning for multi-label sewer defect classification](<https://www.sciencedirect.com/science/article/pii/S0926580525007915>)
		- 针对管道多标签图像人工标注成本高且存在标签噪声的问题，先用无标签图像开展SwAV自监督预训练，再用35,360张标注图像微调分类器，在Sewer-ML完整验证集上取得总体微平均F1 69.11%和F2CIW 54.22%，以远少于全监督基线104万张的标注量获得有竞争力的表现，并通过包含AF沉积标签的错标实例分析揭示标注质量问题。
	- [010]【2026-03】Zhong等
		- 论文：[SewerMan: A vision–language collaborative framework with domain prior for robust multi-label sewer defect classification](<https://doi.org/10.1016/j.asoc.2026.114583>)
		- 针对管道数据标签噪声和视觉特征难以充分利用场景先验的问题，提出SewerMan，将最优传输样本净化、材质文本引导的视觉特征增强与特征选择结合，在含17类缺陷和8种材质的Sewer-ML验证集上取得总体F2CIW 67.00%，为包含管底沉积物的多标签识别提供标签净化和视觉语言协同思路。
	- [011]【2026-06】Li等
		- 论文：[Prototype-based Causal Intervention for Multi-Label Image Classification](<https://openaccess.thecvf.com/content/CVPR2026/html/Li_Prototype-based_Causal_Intervention_for_Multi-Label_Image_Classification_CVPR_2026_paper.html>)
		- 针对多标签图像中背景与共现标签干扰目标判别的问题，提出基于原型的因果干预方法ProCI，通过动态混杂因素原型记忆与自适应特征调整减弱伪相关，在Sewer-ML补充实验中将ResNet-101基线的管底沉积物AF类别AP由56.40%提高至60.88%，为降低沉积物识别对背景共现的依赖提供方法依据。
	- [012]【2026-07】文源等
		- 论文：[一种轻量级地下管道缺陷多标签分类模型MG-MobileViT](<https://doi.org/10.20056/j.cnki.ZNMDZK.20260417>)
		- 针对管道多标签分类模型计算量较大且标签关联利用不足的问题，以MobileViTv3为基础引入多阶门控聚合、图注意力与非对称损失构建MG-MobileViT，在Sewer-ML实验中以7.03M参数取得总体F2CIW 54.15%和mF1 78.27%，为包含沉积物类别的轻量化联合特征建模提供参考。

- 沉积物目标检测与定位
	- [013]【2018-11】Cheng和Wang
		- 论文：[Automated detection of sewer pipe defects in closed-circuit television images using deep learning techniques](<https://doi.org/10.1016/j.autcon.2018.08.006>)
		- 针对管道图像中缺陷位置与类别需要同时识别的问题，在Faster R-CNN中调整ZF特征网络深度、卷积步长及滤波器尺度，以增强细节定位能力，在使用3000张增强训练图像的四类检测实验中取得总体mAP 83.0%，其中合并附着与底部沉积的Deposit类AP为84.5%，说明区域检测能够为沉积位置识别提供基础。
	- [014]【2023-06】Shen等
		- 论文：[Deep learning-based automatic defect detection method for sewer pipelines](<https://doi.org/10.3390/su15129164>)
		- 针对SSD在管道图像中对多尺度缺陷特征利用不足的问题，融合感受野模块、尺度特征、通道注意力和Focal Loss构建EFE-SSD，在从Sewer-ML选取并标注的4000张四类图像、300×300输入条件下，管底沉积物类AP由原始SSD的95.65%提高至96.00%，改善了沉积区域检测表现。
	- [015]【2024-01】Yu等
		- 论文：[A composite transformer-based multi-stage defect detection architecture for sewer pipes](<https://doi.org/10.32604/cmc.2023.046685>)
		- 针对管道多尺度缺陷检测中特征表达不足的问题，采用复合Swin Transformer主干、多阶段检测头及测试时增强和模型集成，在包含沉积CJ的自建城市排水管道图像集上取得总体mAP@0.5 78.6%，较ResNet-50 Faster R-CNN基线的64.5%提高14.1个百分点，为沉积物区域检测提供局部与全局特征联合建模思路。
	- [016]【2025-05】Lu等
		- 论文：[Real-time defect detection in underground sewage pipelines using an improved YOLOv5 model](<https://doi.org/10.1016/j.autcon.2025.106068>)
		- 针对管道缺陷检测中尺度变化和实时推理需求，结合选择性卷积核、双向跨尺度特征融合及SIoU损失改进YOLOv5s，在增强后5472张、含沉积CJ在内的十类图像实验中将总体mAP@0.5由79.1%提高至83.6%，并在RTX 3090上达到69.9 FPS，为沉积物检测的精度与速度兼顾提供依据。
	- [017]【2025-10】Oğurlu等
		- 论文：[Deep Learning for Automated Sewer Defect Detection: Benchmarking YOLO and RT-DETR on the Istanbul Dataset](<https://www.mdpi.com/2076-3417/15/20/11096>)
		- 针对管道检测模型在真实城市巡检场景下的适用性缺少比较的问题，基于伊斯坦布尔2021—2024年巡检影像构建13,491张图像的数据集并将管底沉积物独立标注，对比YOLO与RT-DETR后，YOLOv12l与RT-DETRv2的沉积物类F1分别为72.77%和80.51%，展示了不同检测结构在真实沉积物识别上的性能差异。
