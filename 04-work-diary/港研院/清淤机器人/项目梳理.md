# 课题名称

**基于计算机视觉的管道淤泥识别算法研究**

# 研究内容

## 研究内容 1：管道淤泥的图像数据集构建

1. 基于开源和实采（各种成像环境）的管道淤泥标准图像数据集构建（标签：有无流 + 淤泥类型  + 淤积程度）
2. 图像数据集增广算法研究（基于深度学习的）

## 研究内容 2：基于视觉的管道淤泥识别算法研究

拟输出的三元信息（有无流 + 淤泥类型 + 淤积程度）

1. 不同算法架构在该任务下的性能对比研究
2. 基于对比结果进行算法优化，并辅以实验验证

## 研究内容 3：管道淤泥视觉识别方案的集成与部署

1. 淤泥识别视觉方案集成与设计
2. 视觉方案的嵌入式部署与实验验证

# 创新点

创新点1：一种基于深度学习的图像数据集增广算法

创新点2：一种基于机器视觉的高鲁棒性管道淤泥识别算法
