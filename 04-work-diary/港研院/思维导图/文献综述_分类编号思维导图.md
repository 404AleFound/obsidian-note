# 管道淤积视觉分类文献综述

> 共83篇，沿用原思维导图的分层条目格式，连续编号；以管底沉积物为应用对象，基础方法和综述背景在独立子节点中标明。
> 日期优先采用正式卷期或论文集发表年月，会议仅有召开日期时采用会议月；网络首发、学位论文及预印本另行标明，详细日期和原文图表依据见随附核验说明；数据均保留原文指标、数据集或实验条件。
> “仅识别”指尚未完成淤泥严重度评价，可包括分类、定位与分割；多缺陷论文仅提取沉积物相关内容，整体指标均注明范围；第二类区分识别后分级、直接等级分类和几何量化，第三类区分管道场景实验与通用方法借鉴。
> 各条先概括研究问题、方法与整体表现；原文有淤泥或管底沉积物专项结果时另列分析，未核得专项结果时保留整体分析；混合沉积标签、单个样例和定性结果分别标明，不能当作纯淤泥测试集性能。

## 一、仅进行淤泥识别

- 淤泥存在性分类、数据与标签
	- [001]【2019-05】Li等
		- 论文：[Sewer damage detection from imbalanced CCTV inspection data using deep convolutional neural networks with hierarchical classification](<https://doi.org/10.1016/j.autcon.2019.01.017>)
		- 研究概括：针对正常图像与缺陷图像分布不平衡、不同缺陷难以区分的问题，基于ResNet-18构建分层分类与hierarchical softmax方法，在来自24.7公里管道的验证集和测试集上，将多类别总体准确率由58.9%提高至64.8%，但分类能力仍不足以完全满足实际应用。
		- 淤泥专项分析：在同一数据的验证集与测试集平均结果中，沉积淤塞DS类别的召回率由32%提高至46%、F1由41%提高至48%，精确率却由59%降至50%（表6），该类one-vs-rest准确率也由90.3%降至89.3%（表5），说明分层分类减少了沉积物漏检，同时增加了误报，不能概括为所有沉积物指标均改善。
	- [002]【2019-08】Meijer等
		- 论文：[A defect classification methodology for sewer image sets with convolutional neural networks](<https://doi.org/10.1016/j.autcon.2019.04.013>)
		- 研究概括：针对人工复核管道图像工作量大以及常规数据划分易高估模型表现的问题，采用多标签CNN并按整次巡检开展交叉验证，在逾200万张图像研究中估算，当允许总体缺陷召回率为90%时，需要人工复核的图像量可减少60.5%，为人机协同筛查提供依据。
		- 淤泥专项分析：对于settled deposits，在固定99%召回率时，本文CNN的单图真负率为44.2%，高于重实现对照网络的9.7%（表3），整管真负率为36.3%，高于对照的28.2%（表5），但整管精确率仅11.7%（表6）；作者据此估算沉积物专项人工复核图像量可减少43.7%、整管复核量可减少33.9%（表7—8），说明高召回筛查具备减负潜力，但误报与漏标仍限制直接自动判定。
	- [003]【2021-06】Haurum和Moeslund
		- 论文：[Sewer-ML: A Multi-Label Sewer Defect Classification Dataset and Benchmark](<https://openaccess.thecvf.com/content/CVPR2021/html/Haurum_Sewer-ML_A_Multi-Label_Sewer_Defect_Classification_Dataset_and_Benchmark_CVPR_2021_paper.html>)
		- 研究概括：针对管道缺陷识别缺少大规模公开数据及统一评价条件的问题，构建约130万张图像的Sewer-ML多标签数据集并比较12种算法，最终两阶段Benchmark（TResNet-L结合Xie第一阶段）取得测试集总体F2CIW 55.11%、正常类F1 90.94%，形成统一实验基准。
		- 淤泥专项分析：在Sewer-ML官方测试集上，最终Benchmark的管底沉积物AF类F1为41.93%、F2为59.45%、AP为73.99%，精确率为28.11%、召回率为82.42%（附录表20—24）；与单独TResNet-L相比，AF的F1由40.43%提高至41.93%，但F2由59.55%略降至59.45%，表明该基准仍存在沉积物误报较多及精确率—召回率取舍问题。

		- 淤泥专项分析：调优VGG-19在每类700张的测试条件下，将debris silty（DS，含粉砂沉积）类别中的684张正确归类，原文表2报告该类正确率97.7%，表明该设置下沉积物类别较易识别；但极端类别不平衡实验实际针对裂缝与正常图像，不能据此认为沉积物在1:100不平衡条件下也获得同样结果。

- 沉积物目标检测与定位
	- [013]【2018-11】Cheng和Wang
		- 论文：[Automated detection of sewer pipe defects in closed-circuit television images using deep learning techniques](<https://doi.org/10.1016/j.autcon.2018.08.006>)
		- 研究概括：针对管道图像中缺陷位置与类别需要同时识别的问题，Cheng和Wang通过调整Faster R-CNN的ZF网络深度、卷积核和步长增强局部特征提取，在3000张增强训练图像的四类缺陷实验中将总体mAP由79.8%提高至83.0%，代价是检测速度由20.408降至9.434 FPS。
		- 沉积物专项分析（混合沉积标签）：在同一3000张训练图像的比较中，Deposit类AP由80.2%提高至84.5%，增加4.3个百分点；该类别合并管壁附着沉积和管底沉积，不能将84.5%称为纯淤泥或纯管底沉积识别精度。
	- [014]【2023-06】Shen等
		- 论文：[Deep learning-based automatic defect detection method for sewer pipelines](<https://doi.org/10.3390/su15129164>)

		- 淤泥专项分析：Table 2的管底沉积AF类AP由SSD的95.65%提高至EFE-SSD的96.00%，仅增加0.35个百分点，且低于同表RFB Net的98.41%，因此可以说明相较SSD的小幅改善，不能称沉积类别达到该表最优。
	- [015]【2024-01】Yu等

	- [016]【2025-05】Lu等

	- [017]【2025-10】Oğurlu等
