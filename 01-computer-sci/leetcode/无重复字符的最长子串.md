# 题目

给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长 子串** 的长度。

**示例 1:**

**输入:** `s = "abcabcbb"`
**输出:** `3

# 题解

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
	    unordered_map<char, int> ump;
	    int res = 1;
	    int left = 0;
	    for (int right = 0; right < s.size(); right++) {
		    ump[s[right]]++;
		    while (ump[s[right]] > 1) {
			    ump[s[left]]--;
			    left++;
		    }
		    res = max(res, right - left + 1);
	    }
	    return res;
    }
};
```
